About The System

The Hospital Records Checker is a system that stores and manages patient information using arrays as a data structure. It helps healthcare workers organize patient records efficiently.

How Arrays Are Used

Patient information is stored inside arrays. Each patient record contains details such as ID, name, age, and medical condition. 

let patients = [
 {
   id: 101,
   name: "John Mensah",
   age: 35,
   condition: "Malaria"
 }
